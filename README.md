## Пароли и парольная политика
Минимальная длина пароля задана через файл pwquality.conf, максимальное время жизни через login.defs, причем, так как сначала были созданы пользователи, а потом настроена политика, дополнительно использовалась утилита chage для изменения уже созданных учетных записей.
Пользователям user1 и curator1 пароли (для проверки возможности и невозможности входа через консоль) были заданы уже после настройки парольной политики.
При этом при задании паролей от имени пользователе (sudo -u) правила учитываются жестко, а при задании от имени root лишь показывается предупреждение (настройка enforce_for_root в login.defs).

## Разметка диска
Создание таблицы разделов на дополнительном диске выполнялось через интерактивную консоль fdisk, в связи с чем в вывод history не попало. Информация о диске есть в файле fdisk.out.
